# Security Policy

## Supported versions

| Version | Supported              |
|---------|------------------------|
| 1.x     | Yes (security fixes)   |
| < 1.0   | No                     |

When `2.0.0` is released, `1.x` will keep receiving security fixes for 6 months.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Instead, report privately by:

1. Opening a [GitHub Security Advisory](https://github.com/daycry/phpunit-extension-selenium/security/advisories/new), or
2. Emailing the maintainer through the address listed on the
   [GitHub profile](https://github.com/daycry).

Include as much detail as possible:

- Affected version(s) and platform.
- Steps to reproduce.
- Impact assessment.
- Suggested fix or mitigation if known.

## Disclosure timeline

- Acknowledgement within **7 days** of the report.
- Initial assessment and severity classification within **14 days**.
- Coordinated disclosure within **90 days** of confirmation, unless extenuating
  circumstances apply.

We will credit reporters in the release notes unless anonymity is requested.
